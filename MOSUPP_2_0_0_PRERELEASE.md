# 2.0.0пререлиз

Этот вариант временно заменяет PP-калькулятор в существующем клиентском слоте `ForkRelaxPpSystem.MosuPp`. Это исходный черновик `Relax/MosuPp2`, который лаборатория показывала как MosuPp 2; его параметры, классификатор и формула не перенастраивались.

Текущая одобренная 2.0.0 сохранена в ветке `release/mosupp-2.0.0` и PR https://github.com/morasooma/mosu/pull/7, на коммите b55b468 с исправлением переполнения accuracy. Её исходники `Relax/MosuPpRelax` и неизменяемый снимок `.artifacts/mosupp-releases/2.0.0` также остаются на месте.

Клиентский адаптер использует те же Mp2Features, Mp2Parameters.Default, Mp2Model.Evaluate и Mp2Model.Performance, что и прежняя лабораторная колонка. Для ограничения бонусов модов строится исходная RX/MRX-only версия карты. Счётчики миссов и accuracy берутся из результата; полные однозначные события миссов дают исходную нагрузку Mp2Model.MissLoad, иначе применяется плоское правило. Курсорное расстояние из одобренного реворка не добавляется к формуле черновика.

Подготовка привязана к конкретным difficulty attributes. Live PP рассчитывает только пройденный префикс карты. Для одного набора attributes сохраняется не более 32 моделей префиксов; подготовка временных attributes не пересчитывает модель сразу для каждого префикса. Тем не менее исходная модель заново оценивает каждый новый префикс, поэтому на длинных картах возможны дополнительные затраты CPU; расчёт работает в существующем фоновом RX-пути.

Название настройки: `2.0.0пререлиз`. Ревизия PP-кеша: 46. Числовое значение настройки MosuPp сохраняется, поэтому ранее выбравшие MosuPp получат этот вариант после установки сборки. Отображаемый SR остаётся в существующей клиентской шкале; это замена PP, а не выпуск новой шкалы звёзд. Другие слоты PP не изменяются.

Этот PR не переключает сайт и не пересчитывает серверную БД автоматически. Для возврата одобренной 2.0.0 используется её отдельная ветка/PR; при дальнейшем переключении уже опубликованного клиента нужен новый номер кеша.

## Проверки перед PR

120 тестов Mp2Model, Mp2Adversarial, нового клиентского адаптера, выбора PP-системы и live-пересчёта прошли. Проверены NM/RX, DT, DT с блокировкой AR/OD и DA, HR+HD, accuracy, плоские миссы, полные/противоречивые события миссов и временной префикс без будущих объектов. Release-сборка osu.Desktop успешна (0 ошибок).
