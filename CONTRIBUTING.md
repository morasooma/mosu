# Contributing to the Mosu public source snapshot

This repository is a periodically exported source snapshot of the Mosu client.
It is not the canonical source used to produce official releases, so the source
may be newer or older than a published binary.

Please use the issue tracker and pull-request workflow of the repository where
this snapshot is published. Do not report Mosu-specific problems to ppy or the
osu! project.

Never include credentials, private client proofs, signing material, deployment
configuration, or server-side secrets in an issue or pull request. Changes that
restore score submission, remote replay/spectator frame sending, alternate
server switching, or release signing are outside the scope of the public tree.

By contributing, you agree that your changes may be used under the repository's
licence terms.
