# Шаблон логотипа главного меню Morasooma

Для создания варианта логотипа используйте:

- `morasooma-menu-logo-template.png` — готовый игровой шаблон с белым кольцом;
- `morasooma.png` — исходный силуэт персонажа без кольца.

## Размеры

- холст: `1000 × 1000 px`;
- формат: PNG с прозрачностью;
- центр круга: `X = 500`, `Y = 500`;
- программный круг с градиентом: диаметр `940 px`, границы `30…970 px` по обеим осям;
- важные детали лучше держать внутри радиуса примерно `420 px`, если они не должны пересекать белое кольцо.

Чёрная область, которую некоторые редакторы показывают вокруг персонажа или внутри кольца, является прозрачностью. Не заливайте её цветом: градиент круга рисуется самой игрой в `osu.Game/Screens/Menu/OsuLogo.cs`.

Экспортируйте результат без изменения размера холста. Для добавления нового варианта положите PNG в `osu.Game/Resources/Textures/Menu/` и зарегистрируйте его в `osu.Game/Configuration/ForkMenuLogo.cs`.
